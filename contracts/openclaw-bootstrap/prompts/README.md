# Prompt Pack (Seeded and Sanitized)

These prompts are seeded from AthenaWork operating-system patterns and adapted for this mediated OpenClaw bootstrap harness.

- Planner system prompt: `planner-system.md`
- Densified response schema: `response-schema.md`
- Stage prompts: `stages/*.md`

Rules:

1. Planner proposes only; harness executes.
2. Side effects must be typed events.
3. No vendor-specific or personal details in outputs.

5. Prefer schema-first responses over narrative prose.
